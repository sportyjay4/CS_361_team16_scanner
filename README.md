How to Run

Compile the Java files:

javac *.java

Run the scanner:

java ScannerDemo prog1.jay

Run the parser:

java ParserDemo prog1.jay

Testing

The scanner and parser were tested using prog1.jay.

The scanner successfully identified keywords, identifiers, operators, literals, and separators.

The parser successfully generated an abstract syntax tree containing declarations, assignments, conditional statements, and arithmetic expressions.
